安装并设置 Console 代理后，请添加云凭据，以便 Console 代理具有在 AWS 或 Azure 中执行操作所需的权限。

[role="tabbed-block"]
====
.AWS
--
.开始之前
如果您刚刚创建了这些 AWS 凭据，它们可能需要几分钟时间才能可用。请稍等几分钟，然后将凭据添加到 Console。

.步骤
. 选择 *Administration > Credentials*。
. 选择*组织凭据*。
. 选择*添加凭据*，然后按照向导中的步骤操作。
+
.. *凭据位置*：选择 *Amazon Web Services > Agent*。
.. *Define Credentials*：输入 AWS 访问密钥和私有密钥。
.. *Marketplace Subscription*：立即订阅或选择现有订阅，将 Marketplace 订阅与这些凭据相关联。
.. *审核*：确认有关新凭据的详细信息，然后选择*添加*。




您现在可以转到 https://console.netapp.com["NetApp Console"^]开始使用 Console 代理。

--
.Azure
--
.开始之前
如果您刚刚创建了这些 Azure 凭据，它们可能需要几分钟时间才能可用。请稍等几分钟，然后再将凭据添加到 Console 代理。

.步骤
. 选择 *Administration > Credentials*。
. 选择*添加凭据*，然后按照向导中的步骤操作。
+
.. *凭据位置*：选择 *Microsoft Azure > Agent*。
.. *定义凭据*：输入有关授予所需权限的 Microsoft Entra 服务主体的信息：
+
*** 应用程序（客户端） ID
*** 目录（租户） ID
*** Client Secret


.. *Marketplace Subscription*：立即订阅或选择现有订阅，将 Marketplace 订阅与这些凭据相关联。
.. *审核*：确认有关新凭据的详细信息，然后选择*添加*。




.结果
控制台代理现在拥有在 Azure 中代表您执行操作所需的权限。您现在可以转到 https://console.netapp.com["NetApp Console"^]以开始使用控制台代理。
