注：

. 如果您没有向部署传递防火墙规则并选择让 NetApp Console 为您创建防火墙规则，则仅在主机项目中需要 deploymentmanager.editor。如果未指定规则，NetApp Console 将在主机项目中创建包含 VPC0 防火墙规则的部署。
. 仅当您没有将防火墙规则传递给部署并选择让 Console 为您创建时，才需要 firewall.create 和 firewall.delete。这些权限位于 Console 帐户 .yaml 文件中。如果您使用共享 VPC 部署 HA 对，这些权限将用于为 VPC1、2 和 3 创建防火墙规则。对于所有其他部署，这些权限也将用于为 VPC0 创建规则。
. 对于 NetApp Cloud Tiering，分层服务帐户必须在服务帐户上具有 serviceAccount.user 角色，而不仅仅是在项目级别。当前，如果在项目级别分配 serviceAccount.user，则在使用 getIAMPolicy 查询服务帐户时不会显示权限。
