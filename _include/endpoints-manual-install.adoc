| \https://production-artifacts.cloudmanager.cloud.netapp.com |

+
** \https://bluexpinfraprod.eastus2.data.azurecr.io

* 选项 2:
+
** \https://*.blob.core.windows.net
** \https://cloudmanagerinfraprod.azurecr.io



 a| 
要获取映像，安装程序需要访问这两组端点之一。^1^ 建议使用选项 1 中列出的端点，因为它们更安全。我们建议您设置防火墙以允许选项 1 中列出的端点，同时不允许选项 2 中列出的端点。请注意以下有关这些端点的信息：

* 从 Console 代理的 3.9.47 版本开始，支持选项 1 中列出的端点。与以前版本的 Console 代理不向后兼容。
* Console 代理首先联系选项 2 中列出的端点。如果无法访问这些端点，Console 代理将自动联系选项 1 中列出的端点。
* 如果您将 Console 代理与 NetApp Backup and Recovery 或 NetApp Ransomware Resilience 结合使用，则不支持选项 1 中的端点。在此情况下，您可以禁止选项 1 中列出的端点，同时允许选项 2 中列出的端点。
