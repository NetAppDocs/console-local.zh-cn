如果在*查看*页面上选中*验证代理配置*复选框，则 Console 将在创建 Console 代理后验证其配置。如果 Console 无法部署代理，则会提供可下载的报告以帮助您排除故障。


NOTE: 如果 Console 成功部署代理，则不会生成报告，并会显示一个确认对话框，用于验证部署是否成功。

.步骤
. 在*代理部署失败*对话框中，选择*下载报告*以下载包含验证报告的 PDF 文件。
. 或者，您可以选择*Start over*以返回*Deploy agent*向导并重试。
+
如果要再次尝试部署代理，则必须重新启动整个过程。
