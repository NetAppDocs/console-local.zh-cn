创建角色并将其应用到将用于 Console 代理 VM 实例的服务帐户。

.步骤
. 在 Google Cloud 中创建自定义角色：
+
.. 创建一个 YAML 文件，其中包含 link:reference-permissions-gcp.html["Google Cloud 的控制台代理策略"] 中定义的权限。
.. 从 Google Cloud 激活 Cloud Shell。
.. 上传包含 Console 代理所需权限的 YAML 文件。
.. 使用 `gcloud iam roles create`命令创建自定义角色。
+
以下示例在项目级别创建名为"connector"的角色：

+
[source, gcloud]
----
gcloud iam roles create connector --project=myproject --file=connector.yaml
----
+
https://cloud.google.com/iam/docs/creating-custom-roles#iam-custom-roles-create-gcloud["Google Cloud 文档：创建和管理自定义角色"^]



. 在 Google Cloud 中创建服务帐户：
+
.. 在 IAM & Admin 服务中，选择 *Service Accounts > Create Service Account*。
.. 输入服务帐户详细信息并选择*创建并继续*。
.. 选择您刚刚创建的角色。
.. 完成创建角色的剩余步骤。
+
https://cloud.google.com/iam/docs/creating-managing-service-accounts#creating_a_service_account["Google Cloud 文档：创建服务帐户"^]





.结果
现在，您可以将服务帐户分配给 Console 代理虚拟机实例。
