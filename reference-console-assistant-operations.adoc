= NetApp Console 本地部署中支持的 Console 助手操作
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
使用 NetApp Console 本地部署中的 Console 助手提问自然语言问题并执行选定的存储操作。可用操作取决于您分配的访问角色。注意：有关将 LLM 连接到 Console 助手以启用 AI 功能的文档作为技术预览提供。通过此预览产品，NetApp 保留在正式发布之前修改产品详情、内容和时间表的权利。

在不更改基础架构的情况下，使用 *只读* 模式下的 Console 助手进行问题解答和分析。对于可以更改存储或 ONTAP 系统的受支持操作，请使用 *读/写* 模式。助手会显示建议的更改，并在执行写入操作之前要求确认。



[[console-assistant-capabilities]]
== Console 助理功能

Console 助理支持以下操作类别。可用操作取决于您的版本、配置的 LLM 端点、分配的角色和资源范围。

[cols="28,18,54"]
|===
| 功能 | 访问模式 | 请将其用于 


| 会话引导和搜索 | 只读 | 询问有关 NetApp Console 本地部署、您的存储环境和支持的 ONTAP 管理工作流程的问题。 


| 指标和分析 | 只读 | 在允许的范围内分析支持的容量、性能和其他指标。 


| 存储配置 | 读/写 | 在审核并确认建议的操作后，规划和配置支持的卷或 LUN。 


| 警报调查和修复 | 只读或读/写 | 在更改存储之前，调查活动警报并查看支持的修复操作。 


| ONTAP 管理 | 只读或读/写 | 查看或执行与 Console 关联的系统上受支持的管理操作。 
|===
使用分配的角色和组织、文件夹或舰队范围来确定助手可以访问哪些系统和工作负载。助手不会绕过 Console 本地部署访问控制。



[[metrics-and-analytics]]
== 指标和分析

针对您允许范围内的资源，询问有关支持的存储容量、性能和其他指标的只读问题。当这些详细信息与您的问题相关时，请包括资源、指标和时间段。

助手返回分析，并且不会在*只读*模式下更改存储。

使用 Console 助手对您权限范围内的资源进行自然语言问题查询和高级分析。如果需要对一个卷进行详细的基于时间的分析，包括延迟、吞吐量、资源利用率、容量、事件和预测，请使用 Workload Analyzer。 link:concept-workload-analyzer.html["了解 Workload Analyzer。"]



[[storage-provisioning]]
== 存储配置

用自然语言描述工作负载及其存储要求。助手可以推荐存储类和放置位置，识别缺失的详细信息，并提供配置计划以供审核。

批准计划后，助手会在您的角色权限和存储类策略范围内配置受支持的卷或 LUN 操作。link:task-provisioning-agentic.html["了解如何使用人工智能辅助工作流程配置存储"]。



[[alert-investigation-and-remediation]]
== 警报调查和修复

要求助理调查活动警报。它会分析警报，并可能建议采取补救措施。当受支持的修复操作更改存储时，助理会呈现操作以供审核，并要求在执行前进行确认。

查看建议的修复详细信息并确认操作，然后助手才会更改存储。

link:reference-alert-remediation.html["了解有关警报修复操作的信息。"]



[[ontap-management]]
== ONTAP 管理

以自然语言为已注册的 ONTAP 系统请求受支持的管理操作。当您知道目标集群、存储虚拟机 (SVM) 或资源时，请指定它，以便助手可以使用正确的上下文。

检查您的请求是否仅读取信息或更改 ONTAP 系统，然后确认任何建议的写入操作。可用操作集取决于 Console 本地部署版本和分配给您帐户的权限。

link:task-console-asst-use.html["了解如何使用控制台助手。"]



[[permissions-and-scope]]
== 权限和范围

助手使用登录用户的权限和资源范围。您分配的组织、文件夹或队列范围决定了助手可以访问哪些系统和工作负载。

* 您的角色决定了您可以查看或更改哪些资源和操作。
* 存储类策略限制了 AI 辅助配置。
* 助手不会绕过 Console 本地部署访问控制。


link:reference-iam-predefined-roles.html["了解 NetApp Console 本地部署访问角色"].



[[asynchronous-operations]]
== 异步操作

向助手询问异步运行的受支持的写入操作的状态。助手为未立即完成的操作创建作业。
