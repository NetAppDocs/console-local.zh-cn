= 设置 NetApp Console 本地部署的快速入门
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
安装 NetApp Console 本地部署后，设置您的组织，以便合适的团队可以安全地管理合适的存储资源。使用此清单可规划结构、组织资源、添加成员、配置集成以及启用数据服务。

.必需的访问角色
超级管理员或组织管理员。link:reference-iam-predefined-roles.html["了解访问角色"]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一个"] 安装 NetApp Console 本地部署
[role="quick-margin-list"]
* 查看安装工作流程，了解部署流程。link:concept-deploy-netapp-console-local.html["了解 NetApp Console 本地部署的安装工作流"]。
* 在您的 vCenter 中安装 NetApp Console 本地部署。link:task-install-agent-on-prem-ova.html["安装 NetApp Console 本地部署"]。


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["两个"] 规划组织
[role="quick-margin-list"]
* 了解文件夹和队列如何组织您的资源。link:concept-folders-fleets-overview.html["了解文件夹和舰队"]。
* 了解基于角色的访问控制 (RBAC) 如何授予成员所需的访问权限。link:concept-iam-rbac.html["了解 NetApp Console 本地部署中基于角色的访问控制"]。
* 请查看身份和访问管理工作流。link:task-iam-fleet-mgmt-get-started.html["开始使用 IAM 进行队列和资源管理"]。


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"] 设置您的组织
[role="quick-margin-list"]
* 将存储系统添加到 NetApp Console 本地部署。link:task-add-systems.html["添加存储系统"]。
* 创建与业务结构匹配的文件夹和车队层次结构。link:task-iam-manage-folders-fleets.html["创建文件夹和队列"]。
* 将资源与正确的文件夹和群组关联。link:task-iam-manage-resources.html["将资源关联到文件夹和队列"]。
* 添加成员并分配其初始角色。link:task-iam-manage-members-permissions.html["添加成员并分配角色"]。


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["四个"] 配置集成和服务
[role="quick-margin-list"]
* 与 Active Directory 集成，以便目录用户可以访问 Console 本地部署。link:task-iam-active-directory-integrate.html["与 Active Directory 集成"]。
* 连接您的大型语言模型（LLM），以启用 Console 助理和人工智能辅助管理。link:task-llm-connect.html["连接 LLM"]。
* 配置控制台本地部署如何传递通知。link:task-console-configure-notifications-delivery.html["配置通知传送"]。


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["五"] 设置 NetApp Backup and Recovery
[role="quick-margin-list"]
* link:https://docs.netapp.com/us-en/data-services-backup-recovery/br-start-licensing.html#use-a-netapp-backup-and-recovery-byol-license["获取 NetApp Backup and Recovery 许可证"^].如果不想访问高级备份和恢复服务，则可以跳过此步骤。
* 将 NetApp Backup and Recovery 许可证添加到 NetApp Console 本地部署。link:https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-data-services-licenses.html["将许可证添加到 NetApp Console 本地部署"^]。
* link:https://docs.netapp.com/us-en/data-services-backup-recovery/br-rbac-setup.html["授予用户访问 NetApp Backup and Recovery 的权限"]。
