= 获取有关 NetApp Console 本地部署的帮助
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp 以多种方式为 NetApp Console 本地部署提供支持。全天候提供广泛的免费自助支持选项，例如知识库 (KB) 文章和社区论坛。您可以使用与 NetApp Console 本地部署关联的任何存储资源的序列号注册支持。注册包括通过网络票务提供远程技术支持。



[[use-self-support-options]]
== 使用自助服务选项

这些选项每周7天、每天24小时免费提供：

* 文档
+
当前正在查看的 NetApp Console 本地部署文档。

* https://kb.netapp.com/Cloud/BlueXP["知识库"^]
+
在 NetApp 知识库中搜索可帮助您解决问题的文章。





[[open-a-support-case-with-netapp-console-local-deployment]]
== 使用 NetApp Console 本地部署开立支持案例

使用通过 NetApp Console 本地部署环境管理的其中一个 NetApp 存储系统序列号打开支持案例。

.步骤
. 转到 https://mysupport.netapp.com["NetApp 支持站点"^]并使用您的 NetApp 支持凭据登录。
. 选择 *Cases and Parts > Create Technical Case*。
. 输入与遇到此问题的控制台本地部署产品关联的 NetApp 存储系统的序列号。
. 创建新案例，并为 NetApp Console 本地部署选择适当的类别代码。




[[download-a-support-bundle]]
== 下载支持包

支持包包括最近的日志和配置信息。您可以下载最新的捆绑包，并在需要时将其发送给 NetApp 技术支持。

.步骤
. 选择 *Administration > Support* 以查看支持页面。
. 在支持卡上，选择 *创建* 以创建日志和配置数据捆绑包。
. 创建捆绑包后，选择 *下载*。系统会提示您下载 ZIP 文件。
+
系统一次只保留一个捆绑包。创建新的支持捆绑包将取代之前的支持捆绑包。
